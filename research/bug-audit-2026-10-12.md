# Reproduced customer interface bugs — 12 October 2026

Testing used isolated temporary SQLite databases and browser profiles. No real
customer, administrator, order or catalogue record was modified.

## Fixed

1. **Unavailable saved products had an enabled add button.** The store prevented
   adding the item, but account favourites invited an action it could not complete.
   Favourites now share catalogue availability, pending-price and discount
   rendering, and disable the action with the appropriate localized label.
2. **The profile language reverted after reload.** Saving a language updated the
   profile and document but left the old `lang` query parameter in the URL. The
   next load prioritised that stale parameter. Profile and header language changes
   now use the same action, preserving the URL path, other parameters and hash.
3. **Checkout lost the saved default address.** The account click listener filled
   the address while checkout awaited a catalogue refresh. Checkout then reset
   the form and erased the selection. The account now initializes the saved
   address on a checkout event dispatched after the form reset.

## Validation

- The browser reproducer demonstrated all three failures before the fixes.
- `tools/account-ui-check.mjs` prevents regressions, including all three profile
  languages and two consecutive checkout openings. It never confirms an order.
- Responsive inspection covers 320, 390, 650, 768, 900, 901, 980, 1024, 1100,
  1101, 1280 and 1440 pixels in Persian, Italian and English. No overflowing
  pages or clipped product price/add controls were found in that matrix.
- Mobile routes cover shop, journal, article, product, account and admin sign-in.
- Existing authentication, administration, offers, stock visibility, comments,
  SEO, security, hosting and carousel suites passed during the initial audit.

This is a focused functional audit, not a claim that every possible bug is gone.
Payments, real Google credentials, email delivery and production indexing retain
their existing launch limitations. Railway publication must be verified separately.
